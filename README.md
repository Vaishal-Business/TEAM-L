# Programming Tools interactive deck

Open `index.html` in a modern browser. Use arrow keys / Space, click the dots, swipe, or use the bottom controls. `O` opens overview, `F` opens fullscreen, and `R` replays the current scene (on the final slide it restarts the deck).

Drop these optional WebP screenshots into `assets/screens/`; the deck displays a clear placeholder until each is present:

- `ide-python-idle.webp` — Python IDLE/IDE editor, run controls, and console
- `terminal-compile.webp` — terminal compiling a C program with gcc
- `terminal-python.webp` — Python shell running a program line by line
- `ms-word.webp`, `ms-excel.webp`, `ms-powerpoint.webp`, `gimp.webp`, `firefox.webp`
- `billing-software.webp`, `library-management.webp`, `school-management.webp`, `ubuntu-desktop.webp`

Also place the circular logo at `assets/logo.webp` and the fallback font at `fonts/GeistPixel-Circle.woff2` if available. All paths and editable presentation content live in `config.js`.
